# NextRole product direction

Help students find suitable openings, prepare truthful applications and understand what happens next. Discovery must remain useful without LLM credits; optional AI uses the student's own enabled connections after consent.

| Student task | Current experience | Evidence boundary |
| --- | --- | --- |
| Find eligible openings | Shared configured public employer/board feeds and explicit role, location, arrangement, experience and batch matching | A match is not proof of all eligibility. Unknown requirements are shown for review. |
| Bring another opportunity | Private text/JSON-LD import; deliberate browser capture from a LinkedIn, Unstop or supported ATS page | Captured jobs are private and unverified; no whole-platform coverage claim. |
| Supply career facts | Reviewed education, skills, experience, projects and links; optional role-based résumé originals | No fabricated credentials, account access inferred from a profile URL or silent fact confirmation. |
| Work with Scout | Per-job chat, fixed-template résumé, explained internal fit score and reviewed conversational corrections | No universal employer ATS score. Providers receive only disclosed, consented input. |
| Apply | External application page and explicit Applied confirmation; optional scoped browser companion | Off by default. No CAPTCHA bypass, unknown declarations, blind retries or false submission success. |
| Prepare for next stages | Independent milestones, official guides, labelled candidate reports and original practice | An update date is not an interview date. Practice is not an exact previous-year question. |
| Stay informed | In-app updates, optional Web Push and prepared nightly email delivery | Real email needs sender activation; acceptance is not inbox delivery. |
| Improve the product | Skippable ratings, help inbox, monthly survey, private user analytics and aggregate host metrics | Analytics opt-out and workspace export/deletion remain available. |

Next steps are real browser/device testing, sender-domain activation, a small observed campus pilot and evidence-led source expansion. An API key does not grant permission or technical access to an unrelated platform. Keep public discovery, personal AI assistance and personal application actions separately authorized.
