Scout Companion — developer beta setup guide
Version 0.3.1
https://nextrole-scout.vercel.app/extension

The normal student installation will use the approved Chrome Web Store listing. This manual is only for intentional unpacked testing before publication. Scout now includes a recent matched-job inbox and optional desktop notifications. Connected feeds refresh centrally; the extension does not unlock LinkedIn, Unstop or Internshala feeds. No AI key is required for matching or tracking.

1. OBTAIN THE DEVELOPER TEST BUILD
Use the developer package supplied by the project maintainer or included in the source handoff. This is not the student installation route and is not advertised on NextRole’s normal install page. Extract all files into a permanent folder such as Documents/Scout-Companion. Open that folder and make sure manifest.json is directly inside it. Keep the extracted folder after installation; the browser loads a test build from there.

2. LOAD SCOUT IN YOUR BROWSER
In desktop Chrome, enter chrome://extensions in the address bar. In desktop Edge, enter edge://extensions. Turn on Developer mode, choose Load unpacked, then select the extracted folder containing manifest.json. Select the folder, not the ZIP. This beta is not listed in the Chrome Web Store or Edge Add-ons. Chrome 116 or later, or a current compatible Edge release, is required. Firefox, Safari and mobile browsers are not supported by this package.

3. PIN SCOUT AND OPEN IT
Open the browser’s Extensions menu (the puzzle icon), find NextRole Scout Companion and pin it. Click its icon, then Open Scout panel. If the browser cannot open a side panel, Scout opens in its own extension tab. Open Connection in Scout.

4. CREATE YOUR DEVELOPER PAIRING TOKEN IN NEXTROLE
For unpacked testing, sign in to your own NextRole account. Open Preferences → Auto-Apply → Manage browser connection / developer testing. Tick Allow Matched-job inbox access, which includes Workspace assistance, then choose Create / replace pairing token. Copy the token once. Creating another token revokes the previous token. Pairing expires after 30 days. Existing tokens gain no new access. The normal Connect NextRole button becomes available when the publisher registers the official store extension ID.

5. CONNECT AND CHOOSE YOUR JOB CHECKS
Paste that token into Scout → Connection → Developer beta: connect with a token, then Verify & pair. Check for Matched-job inbox & workspace access and an expiration date. Turn on Check my NextRole matches in the background. Choose desktop alerts separately if wanted; the browser asks for notification permission. The initial inbox check is quiet. Later new matches notify once while Chrome runs. The inbox contains up to 30 current matches from the last 60 match alerts within 30 days; source refresh time is shown. Application queue assistance remains paused. Never paste an AI key or job-board password.

6. SAVE YOUR FIRST JOB
Open an individual job page. Click the pinned Scout icon while that job tab is active, open the panel and choose Use the current job page. If its link is unavailable, paste the original HTTPS job URL yourself. LinkedIn, Unstop, Internshala and other boards use the link and full job text you paste. Supported employer ATS pages can preview one structured JobPosting. Review the title, employer, location, work arrangement, job type and full description, including experience and graduating batches. Leave unknown requirements unspecified. Tick the review confirmation and choose Save to NextRole.

7. CHECK THE RESULT AND PREPARE
The saved job should show its match/review explanation and tracking status. Open Scout · résumé & fit to open that exact job in NextRole. Review your confirmed career facts before building a résumé or checking résumé/JD compatibility. This internal compatibility indicator is not an external ATS guarantee. Existing Applied and Not interested choices, notes and history stay preserved when the same canonical link is saved again. Confirm I’ve applied only after submitting on the employer website.

8. USE DRAFTS, UPDATE OR DISCONNECT
Keep a local draft when offline, then review and save it yourself when online. Up to 20 explicit drafts stay in this browser; nothing uploads automatically. To update an unpacked installation, extract the new ZIP over the same folder and click Reload on Scout’s browser Extensions card. Reopen the popup and check the version. Queue assistance and automatic submission are separate opt-ins. Disconnect removes the local token and pauses this browser; Revoke companion access in NextRole invalidates the token everywhere. Delete drafts in Connection or uninstall Scout to remove its local storage.

TROUBLESHOOTING

The browser cannot find manifest.json
Extract the ZIP first. Choose the folder whose immediate contents include manifest.json, popup.html and background.mjs. Do not select the ZIP or a parent folder that contains another Scout-Companion folder.

Developer mode or Load unpacked is unavailable
A school or work browser may restrict extension installation. Ask your device administrator for an approved installation. You can still use NextRole’s private text import and Scout on the website. Do not change administrator controls or browser protections.

I cannot see the side panel or the job link
Pin Scout, then click its icon while the job tab is active. The current-tab permission comes from that click. Reopen the popup after changing job tabs. In an extension-tab fallback, Scout can use the job tab you launched it from. If that tab was closed or navigated, paste the correct original link. Internal browser pages and web-store pages cannot be read.

Pairing expired, was revoked, or has limited access
Create a fresh token in your own NextRole account with Allow Workspace assistance checked. Paste it into Connection → Verify & pair. Replacing a token disconnects the previous one and pauses browser queue assistance. Your existing local drafts remain available for deliberate review.

The connection is refused or temporarily unavailable
Keep a local draft. Check that NextRole opens normally, then try Connection → Check connection when the service is available. A refused request is not fixed by pasting an AI key or changing job filters. If it continues, use NextRole → Help & feedback and report the visible error, browser version and extension version. Never include the pairing token or private résumé content in feedback.

The job does not preview automatically
This is expected on LinkedIn, Unstop, Internshala and unknown websites: paste the original link and full JD yourself. Employer pages with missing or multiple structured job records also use the paste workflow. Scout does not crawl accounts or bypass login walls, CAPTCHA or site restrictions.

My job does not match or says Needs review
Compare the displayed experience, graduation batch, degree, location and other requirements with your saved preferences and the full JD. Unknown eligibility stays uncertain. A job requiring 3 or more years is excluded for a zero-experience profile when that requirement is present in the supplied title/JD. A saved private import remains availability-unverified.

The application queue is paused or the result is uncertain
Saving jobs does not need the queue switches. For optional reviewed ATS assistance, enable the queue separately in NextRole and Scout and queue a saved exact résumé for a supported employer source. Auto-submit needs its own explicit opt-in. Unknown answers, declarations, eligibility uncertainty and CAPTCHA stop automation. After an uncertain submission, check the employer page first; Scout never retries automatically.
